The runtime field geometry, articulated food rigs, interface, and game implementation were created for this project. The game does not embed or execute Google’s game code.

Development tools include TypeScript (Apache-2.0), Vite (MIT), esbuild (MIT), tsx (MIT), Playwright (Apache-2.0), Prettier (MIT), and concurrently (MIT). Their license texts are distributed with their npm packages.
